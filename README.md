# Career Journey AI 🤖

An AI-powered career guidance platform aligned with Vision 2030 🇸🇦🇦🇪 and Vision 2035 🇵🇰

## SDG Alignment
- SDG 8: Decent Work & Economic Growth
- SDG 4: Quality Education

## Tech Stack
- Frontend: Next.js, TypeScript, Tailwind CSS (Vercel)
- Backend: Flask, Python, scikit-learn (Hugging Face)
- Data: O*NET (1,000+ careers), Tech Salary Dataset (Kaggle)
- AI: NLP (TF-IDF + Logistic Regression), Random Forest

## Features
- 3 Dashboards: User, Admin, Client
- 3 Languages: English, Arabic, Urdu
- 3 Regions: UAE, KSA, Pakistan
- Voice input & CV upload
- Skills gap analysis & career roadmap
- Vision 2030/2035 alignment
